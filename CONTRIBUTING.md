# 🤝 Как внести вклад

Спасибо, что хотите помочь проекту **Daniil_Himik** («ХИМИК»)!

## 🐛 Нашли ошибку?

1. Проверьте, не была ли эта проблема уже описана в разделе Issues репозитория.
2. Если нет — создайте новый Issue с описанием проблемы, шагами для воспроизведения и ожидаемым поведением.

## 💡 Предложение новой функции

Создайте Issue с описанием вашей идеи и тем, как она улучшит тренажёр по химии.

## 🛠️ Хотите написать код?

1. Сделайте форк репозитория и клонируйте его локально.
2. Установите зависимости с помощью **Bun**: `bun install`.
3. Инициализируйте базу данных (Prisma ORM + SQLite): `bun run db:push`.
4. Запустите проект в режиме разработки: `bun run dev`.
5. Внесите изменения в отдельной ветке и проверьте код линтером: `bun run lint`.
6. Отправьте изменения и создайте **Pull Request** в ветку `main` — все изменения проходят проверку через Pull Request.

## 📝 Стиль кода

*   **Стек:** Next.js 16, TypeScript, Tailwind CSS 4, Prisma ORM + SQLite, Bun.
*   Соблюдайте типизацию TypeScript и правила линтера (`bun run lint`).
*   Используйте понятные сообщения коммитов.
*   Внося вклад в проект, вы соглашаетесь с тем, что ваши изменения распространяются на условиях лицензии **MIT** (см. файл `LICENSE`).
